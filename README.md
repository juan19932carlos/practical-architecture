# domain-driven-desing

Personal workspace that implements the steps of "Architecture Patterns with Python" (domain-driven design, DDD), with the API implemented in both Python and JavaScript. There is no frontend. Tool versions (Node, pnpm, Python, uv) are pinned in `mise.toml`: run `mise install` once, then use pnpm for JavaScript packages and uv for Python packages. Documentation and diagrams are rendered with [Renderizr](https://github.com/FormulaMonks/renderizr) (model, docs and decisions live in `architecture/`; see `architecture/docs/01-getting-started.md` for the build commands).
