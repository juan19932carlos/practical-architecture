# Git and releases

- Branches, pull requests, branch names, commit messages and git hooks: `architecture/docs/03-git-strategy.md`.
- Tag names, release notes and the checklist before a tag: `architecture/docs/02-release-strategy.md`.
- Never move or delete a tag. Fixes go to `main`.
- Write every pull request description from `.github/pull_request_template.md`. Keep its sections and order. The page `architecture/docs/03-git-strategy.md`, under "Pull request description", says what goes in each one.
